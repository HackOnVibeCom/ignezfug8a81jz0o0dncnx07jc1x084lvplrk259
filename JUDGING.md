# COMMN judging walkthrough

[Live application](https://commn-three.vercel.app/) · [Video walkthrough](https://youtu.be/uayxJEogv9E)

1. Select English from the language menu and click **Matching**.
2. Enter this project brief: “I am building an MVP for a marketplace. I need a product designer for UX and Figma, a full-stack developer for React and API, and a brand strategist for launch marketing.”
3. Click **Find specialists** to see the suggested team. Open a portfolio or adjust the selection.
4. Click **Review contributions** to see how the selected specialists can help.
5. Click **Create project**, enter **Marketplace MVP**, and use the blue button to open its team chat.

The prototype uses sample profiles and stores demo projects and messages in the browser.
